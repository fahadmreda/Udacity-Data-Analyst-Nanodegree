## 🚀 Projects Overview

### 🎬 1. Investigate a Dataset (TMDb Movies)
* **Goal:** Perform an Exploratory Data Analysis (EDA) on a 10,000-movie dataset from The Movie Database (TMDb).
* **Key Insights:** Identified that movie budgets strongly correlate with revenue, and specific film runtimes maximize viewer ratings across decades.
* **Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.
* **📂 [View Project Folder](./Project-1-Investigate-TMDb-Dataset/)**

### 🐕 2. Wrangle and Analyze Data (Historical Weather Data)
* **Goal:** This project investigates the relationship between weather variables and air quality by combining weather observations collected from the Open-Meteo API with air pollution measurements from a publicly available CSV dataset. The datasets will be assessed, cleaned, merged, and analyzed to identify patterns between weather conditions and pollution levels..
* **Key Insights:** Data wrangling project combining hourly weather (API) and air quality (Kaggle) data — 4,000 records cleaned across 2 quality + 2 tidiness issues; found no significant correlation between temperature/wind speed and PM2.5.
* **Tech Stack:** Python, Requests, Tweepy API, Beautiful Soup, Pandas.
* **📂 [View Project Folder](./Project-2-Wrangle-And-Analyze-Data/)**

### 📊 3. Data Visualization (Ford GoBike — February 2019 Trip Data Exploration)
* **Goal:** Analyzed 183K+ bike-share trips to compare usage patterns between Subscribers (members) and Customers (casual riders).
* **Key Insights:** Exploratory data analysis of 183K+ Bay Wheels bike-share trips (Feb 2019), uncovering a clear behavioral split between Subscriber commuters and Customer leisure riders — using Python, pandas, matplotlib, and seaborn across 7 univariate, bivariate, and multivariate visualizations.
* **Tech Stack:** Seaborn, Matplotlib, Tableau, Jupyter Slides.
* **📂 [View Project Folder](./Project-3-Data-Visualization/)**
